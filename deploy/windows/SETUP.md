# EVE Empire — установка (Windows)

Локальный веб-кабинет для альтов EVE Online. Один exe + SQLite, никаких
внешних зависимостей. Всю инфраструктуру (базу данных, схему) сервер
создаёт сам при первом запуске.

## 1. Зарегистрируй приложение EVE SSO

На [developers.eveonline.com](https://developers.eveonline.com) создай
приложение:

- Callback URL: `http://localhost:8080/callback`
- Scopes: отметь все — сервер сам запросит только нужные.

Получишь Client ID и Secret Key.

## 2. Настрой .env

Скопируй `.env.example` в `.env` рядом с `eve-empire.exe`, впиши
`EVE_CLIENT_ID`, `EVE_CLIENT_SECRET` и сгенерируй `ENCRYPTION_KEY`
(64 hex-символа, команда генерации — в комментарии файла).

## 3. Статическая база (рекомендуется)

Состав руд, чертежи, атрибуты и иконки читаются из локальной копии
официального Static Data Export (~250 МБ). Собери её один раз:

```
sdeimport.exe -db sde.db
```

Импорт качает данные с серверов CCP и может занять заметное время
(иконки идут параллельно; повторный запуск докачивает недостающее).
Без `sde.db` кабинет работает, но часть страниц будет неполной.

## 4. Запуск

```
eve-empire.exe
```

Открой http://localhost:8080 и добавь персонажей через логин EVE SSO.
База `eve-empire.db` создастся автоматически в текущей папке; в ней
лежат токены персонажей (зашифрованы твоим `ENCRYPTION_KEY`), поэтому
запускать сервис стоит только дома (LAN/VPN), не на публичном хостинге.
