# EVE Empire

Локальный веб-кабинет для управления альтами EVE Online через ESI: один бинарник на Go
плюс SQLite, без CGO и без внешних зависимостей во время работы. Рассчитан на запуск
дома (LAN/VPN), а не на публичный хостинг: токены персонажей лежат в локальной базе.

## Что внутри

**Обзор империи** — сводка по всем альтам, кошельки, обучение, производственные линии,
планетарка, добыча и структуры корпораций.

**Страницы персонажа** — навыки, кошелёк, индустрия, маркет, имущество, чертежи,
планеты, клоны и почта (с уведомлениями и счётчиком непрочитанных).

**Инструменты**

| | |
|---|---|
| Таблица руд | руда, лёд, лунная руда и газ: состав переработки из SDE, цены по живому ордербуку Житы, вердикт «перерабатывать или продавать»; выход считается по навыкам выбранного альта и настройкам структуры |
| Расчёт производства | во сколько обойдётся прогон чертежа, если комплектующие купить в Жите; рекурсивное «сделать или купить» по каждому компоненту |
| Наблюдение за рынком | вотчлист (PLEX, инжекторы, топливные блоки): ордербук и дневная история |
| Планетарная промышленность | схема P0→P4, расчёт потребностей, шаблоны колоний в формате игры |
| Планировщик навыков | разбор плана в игровом формате, пересборка порядка, подбор ремапа, оценка имплантов и ускорителей |
| Управление флотом | единственная страница, которая пишет в игру: состав, перемещения, приглашения, хроника |

## Запуск

Нужен Go 1.26+ и приложение EVE SSO с callback `http://localhost:8080/callback`
(регистрируется на [developers.eveonline.com](https://developers.eveonline.com)).

```
cp .env.example .env      # вписать EVE_CLIENT_ID/SECRET и ENCRYPTION_KEY
go build -o eve-empire ./cmd/server
./eve-empire              # http://localhost:8080
```

`ENCRYPTION_KEY` — 32 байта в hex (`openssl rand -hex 32`), им шифруются refresh-токены.

## Статическая база

Половина функциональности (состав руд, чертежи, атрибуты, иконки) читается из локальной
копии официального Static Data Export. В репозитории её нет — она весит около 250 МБ и
собирается на месте:

```
go build -o sdeimport ./cmd/sdeimport
ESI_USER_AGENT="mytool (contact: you@example.com)" ./sdeimport -db sde.db
```

Без `sde.db` приложение работает, но часть данных недоступна.

## Деплой

`deploy/` — сборка статического arm64-образа без Docker (`cmd/mkimage` пишет тар формата
`docker save`) и инструкция по запуску в контейнере на MikroTik RB5009.
