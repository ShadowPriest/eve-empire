# EVE Empire

Локальный веб-кабинет для управления альтами EVE Online через ESI: один бинарник на Go
плюс SQLite, без CGO и без внешних зависимостей во время работы. Рассчитан на запуск
дома (LAN/VPN), а не на публичный хостинг: токены персонажей лежат в локальной базе.

## Что внутри

**Обзор империи** — сводка по всем альтам, кошельки, обучение, производственные линии,
планетарка, добыча и структуры корпораций.

**Страницы персонажа** — навыки, кошелёк, индустрия, маркет, имущество, чертежи,
планеты, клоны и почта (с уведомлениями и счётчиком непрочитанных).

**Инструменты**

| | |
|---|---|
| Таблица руд | руда, лёд, лунная руда и газ: состав переработки из SDE, цены по живому ордербуку Житы, вердикт «перерабатывать или продавать»; выход считается по навыкам выбранного альта и настройкам структуры |
| Расчёт производства | во сколько обойдётся прогон чертежа, если комплектующие купить в Жите; рекурсивное «сделать или купить» по каждому компоненту |
| Наблюдение за рынком | вотчлист (PLEX, инжекторы, топливные блоки): ордербук и дневная история |
| Планетарная промышленность | схема P0→P4, расчёт потребностей, шаблоны колоний в формате игры |
| Планировщик навыков | разбор плана в игровом формате, пересборка порядка, подбор ремапа, оценка имплантов и ускорителей |
| Управление флотом | единственная страница, которая пишет в игру: состав, перемещения, приглашения, хроника |

## Запуск

Нужен Go 1.26+ и приложение EVE SSO с callback `http://localhost:8080/callback`
(регистрируется на [developers.eveonline.com](https://developers.eveonline.com)).

```
cp .env.example .env      # вписать EVE_CLIENT_ID/SECRET и ENCRYPTION_KEY
go build -o eve-empire ./cmd/server
./eve-empire              # http://localhost:8080
```

`ENCRYPTION_KEY` — 32 байта в hex (`openssl rand -hex 32`), им шифруются refresh-токены.

### Как войти в первый раз

Пароля нет: личность подтверждает EVE Online. Любая страница без сессии уводит на
`/login` с кнопкой «Войти через EVE Online». Входить можно любым персонажем,
который уже добавлен в кабинет, — попадёшь к нему со всеми альтами.
**Первый вход в пустую базу заводит кабинет администратора**, дальше остальные альты
добавляются изнутри («Настройки» → «+ Добавить персонажа»).

**Два режима входа.** Основная кнопка просит полный набор прав — это режим «свой
альт», в нём работает весь кабинет. Под ней ссылка «Войти с доступом только к
производству»: она просит ровно четыре права (публичная карточка, навыки, очередь
обучения, производственные задания) и больше ничего — для тех, кто готов показать
руководству корпорации только производство. Узкий токен кабинет не ломает: вкладки,
на которые прав нет, просто не показываются, а сводные страницы такого персонажа
молча пропускают. Метку набора видно в настройках у каждого персонажа, там же —
ссылка «войти с полным набором», если передумал.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `SIGNUP` | `first` | кто может завести НОВЫЙ кабинет: `first` — только первый вход в пустую базу, `open` — любой неизвестный персонаж, `closed` — никто (вход только уже добавленными), `corp` — член корпорации, в которой есть персонаж администратора |
| `SESSION_DAYS` | `90` | срок жизни сессии (куки `eve_session`) |

Персонаж принадлежит ровно одному кабинету: вход персонажем из чужого кабинета его
не переносит, а добавление такого персонажа отклоняется.

### Корпорация

Раздел «Корпорация» показывает CEO производственные возможности тех членов его
корпорации, кто сам согласился ими поделиться: уровни производственных навыков и
сколько у человека производственных и исследовательских линий, сколько из них
занято. Корпорация считается «своей», если её CEO (публичное поле карточки
корпорации) — один из персонажей кабинета.

**ESI такого не даёт.** У руководства корпорации нет ни одного эндпоинта, который
отдавал бы навыки или производственные линии её членов, и обойти это нечем. Всё,
что видно в разделе, человек показал сам: вошёл в свой кабинет ссылкой «Войти с
доступом только к производству» — страница входа прямо пишет, что навыки и линии
этого персонажа будут видны руководству его корпорации. Данные читаются его же
токеном и только теми правами, что он дал.

Согласие отзывается там же, где выдано, — в своём кабинете: «Настройки», галочка
«делиться с руководством корпорации: навыки и линии» у каждого персонажа. Членство
в корпорации проверяется по публичной карточке при каждом открытии страницы: ушёл
из корпорации — строка пропала.

## Статическая база

Половина функциональности (состав руд, чертежи, атрибуты, иконки) читается из локальной
копии официального Static Data Export. В репозитории её нет — она весит около 250 МБ и
собирается на месте:

```
go build -o sdeimport ./cmd/sdeimport
ESI_USER_AGENT="mytool (contact: you@example.com)" ./sdeimport -db sde.db
```

Без `sde.db` приложение работает, но часть данных недоступна.

## Деплой

`deploy/build-all.ps1` за один проход собирает все дистрибутивы: образ arm64 для контейнера
на MikroTik (без Docker, `cmd/mkimage` пишет тар формата `docker save`), zip с exe для Windows
и `.deb` со службой systemd для Debian/Ubuntu (без dpkg-deb, `cmd/mkdeb`). Инструкция по
роутеру — [deploy/README.md](deploy/README.md), по deb — [deploy/debian/SETUP.md](deploy/debian/SETUP.md).
